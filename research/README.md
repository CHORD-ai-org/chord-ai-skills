# Research

Research is staging. Promote a source into `skills/` only after verification.

| File | Purpose |
| --- | --- |
| `SOURCES.md` | Repository-level candidate table |
| `QUERIES.md` | Discovery queries and CLI commands |
| `SAMPLES.md` | Observations from downloaded upstream samples |
| `EXPERT_FIELDS.md` | Expert-field skill candidates |
| `LICENSES.md` | License facts and legal decisions |
| `log/` | Append-only daily research logs |

## Meaning of verified

`verified` means:

1. README opened directly.
2. LICENSE opened directly.
3. One `SKILL.md` opened in full.
4. Scripts and evals presence recorded.
5. Upstream commit pinned.

Raw downloaded files stay in local scratch and are not committed.
