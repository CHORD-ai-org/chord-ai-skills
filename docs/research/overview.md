# Research overview

`research/` is the intake and evidence workspace. It is not documentation prose.

| File | Purpose |
| --- | --- |
| `SOURCES.md` | Repository-level candidates |
| `QUERIES.md` | Discovery queries and CLI commands |
| `SAMPLES.md` | Observations from downloaded samples |
| `EXPERT_FIELDS.md` | Expert-field candidates |
| `LICENSES.md` | License matrix |
| `SECURITY.md` | Supply-chain review |
| `QUALITY_AUDIT.md` | Domain quality audit |
| `METRICS.md` | Current repository metrics |
| `log/` | Daily append-only logs |

Canonical guide: [`research/README.md`](../../research/README.md).
