# Concepts

| Term | Meaning |
| --- | --- |
| Skill | A directory with one `SKILL.md` |
| Category | One of eight stable taxonomy folders |
| Status | Maturity label in frontmatter |
| Pointer | A skill that links to an upstream source |
| Evidence | A real task run recorded after using a skill |

Canonical format: [`templates/SKILL.md`](../../templates/SKILL.md).
