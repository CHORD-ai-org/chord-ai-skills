# Skill format

Required frontmatter fields:

```yaml
name:
description:
category:
status:
inputs:
outputs:
fails_when:
verify:
source:
```

Recommended body section after the title:

```markdown
## Brief info
```

Required body sections:

```markdown
## Trigger
## Steps
## Hard rules
## Verify
```

Canonical template: [`templates/SKILL.md`](../../templates/SKILL.md).
